⚡ Teams / SharePoint Live Auto-Sync

Automatically sync changes whenever your team updates DQ - Testing Tracker - 2026.xlsm in Teams.

⚡ High-Speed Office Script for Excel Online

1. Open your tracker Excel file in Teams / Excel Online.

2. Copy the script from scripts/excel_office_sync.ts into Automate → New Script.

3. Replace SYNC_URL with the Office Script JSON Sync Endpoint above, then save the script.

4. Run the script whenever the workbook changes. It reads all supported sheets and replaces the tracker data with the latest workbook contents.

5. Use ... (More options) → Add button to make the sync a one-click action for the team.

📋 Power Automate Webhook (Automatic Cloud Flow)
  1. Open Power Automate with your Sky Microsoft 365 account.
  2. Click Create → Automated cloud flow.
  3. Choose trigger: When a file is created or modified (properties only) (Site: DQ-Testing, Folder: /Shared Documents/General).
  4. Add Action 1: Get file content (SharePoint).
  5. Add Action 2: HTTP (Method: POST, URI: [Paste Power Automate Webhook Endpoint above], Body: [File Content]).

For the Excel Run script action, use scripts/excel_power_automate_sync.ts. The direct fetch-based script is not compatible with Power Automate.
